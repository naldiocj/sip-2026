# Tasks — SIP

## Convenção

Cada Sprint possui um directório em `prompts/tasks/`.

```
prompts/tasks/
├── sprint-00-bootstrap/
│   ├── TASK-001-repository-analysis.md
│   ├── TASK-002-backend-bootstrap.md
│   ├── TASK-003-frontend-bootstrap.md
│   ├── TASK-004-infrastructure.md
│   ├── TASK-005-observability.md
│   ├── TASK-006-testing.md
│   └── TASK-007-documentation.md
└── README.md
```

## Formato de cada Task

- **Objective**: o que fazer
- **Scope**: fronteiras do que incluir
- **Dependencies**: dependências entre tasks
- **Implementation**: passos concretos
- **Acceptance Criteria**: checklist
- **Tests**: testes obrigatórios
- **Definition of Done**: quando está concluída

## Regra

Executar **uma Task por vez**. NUNCA avançar sem validação completa.
